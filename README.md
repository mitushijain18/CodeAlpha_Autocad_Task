# AutoCAD Design Task

## Project Overview

This project is completed as part of the CodeAlpha Design and Engineering Internship. The project focuses on creating technical drawings and designs using AutoCAD software.

The main objective of this task is to understand Computer-Aided Design (CAD) concepts, create accurate 2D drawings, and improve drafting skills using industry-standard design tools.

## About AutoCAD

AutoCAD is a Computer-Aided Design (CAD) software used for creating precise 2D drawings and 3D models. It is widely used in architecture, mechanical engineering, civil engineering, and product design.

AutoCAD helps designers create accurate technical drawings with proper dimensions, annotations, and professional layouts.

# CodeAlpha 2D Drafting Using AutoCAD

## Project Overview

This project is completed as part of the CodeAlpha Internship and focuses on creating accurate 2D technical drawings using AutoCAD. The project involves designing and drafting engineering drawings with proper dimensions, annotations, layers, and geometric accuracy.

The main objective of this task is to understand the fundamentals of Computer-Aided Design (CAD) and develop skills in creating professional 2D drawings used in engineering and design fields.

## About AutoCAD 2D Drafting

AutoCAD is a computer-aided design software used for creating precise engineering drawings. 2D drafting involves creating two-dimensional representations of objects, structures, and layouts using different drawing tools and commands.

This project demonstrates the use of AutoCAD commands and drafting techniques to create accurate and well-organized designs.

## Working Process

The project was completed using the following workflow:

1. Understanding the drawing requirements
2. Setting up drawing units and workspace
3. Creating basic geometric shapes
4. Applying modification commands
5. Adding dimensions and annotations
6. Organizing objects using layers
7. Checking accuracy and finalizing the drawing
8. Saving and exporting the final design
